# Character Files

A React-based file download manager that displays files from various devices and allows users to select and download them.

## Getting Started

After cloning and running `npm install` to install the dependencies you have access to the following commands

```bash
npm start     # Start development server and see the app in action
npm run build # Build for production where the artifacts will be in `/dist`
npm test      # Run unit tests - All test should be passing!
npm run e2e   # Run e2e test - All test should be passing!
```
